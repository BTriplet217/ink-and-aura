# Ink & Aura

A watercolour RPG about carrying feelings, by Blaine Triplet.

Play / install: https://btriplet217.github.io/ink-and-aura/

On Android (Chrome): open the link, then ⋮ → **Install app** / **Add to Home screen**.
On desktop (Chrome / Edge): open the link and click the install icon in the address bar.

The installed app updates itself whenever you're online, and keeps working offline.
